# Prediksi Diabetes Berdasarkan Data Demografi dan Klinis

## Deskripsi Proyek
Project ini dibuat untuk memenuhi tugas kelompok mata kuliah Fundamental Data Analyst. Proyek ini membahas analisis dan prediksi diabetes berdasarkan data demografi dan klinis menggunakan Machine Learning.

## Tujuan
Mengetahui bagaimana data demografi dan klinis dapat digunakan untuk membantu memprediksi status diabetes.

## Dataset
Dataset yang digunakan adalah Diabetes Prediction Dataset dengan:
- 100.000 baris data
- 8 fitur
- 1 variabel target

## Metode Analisis
Proyek ini menggunakan tahapan CRISP-DM:
1. Business Understanding
2. Data Understanding
3. Data Preparation
4. Modelling
5. Evaluation

## Algoritma
- Logistic Regression
- Gradient Boosting

## Tools yang Digunakan
- Python
- Google Colab
- Pandas
- Scikit-learn
